# 🛠️ TechKart Admin Dashboard

The **TechKart Admin Dashboard** is a powerful admin panel designed for managing the TechKart eCommerce platform.  
Admins can efficiently manage products, categories, and customer orders with ease.

---

## 🌐 Live Demo
[Click here to view live project](https://tech-kart-admin.vercel.app)

---

## 📌 Features

### 🔑 Authentication
- Firebase Authentication ka use login/signup ke liye
- Protected Routes for Admin access

### 📦 Product & Category Management
- Add, Edit, Delete products
- Add, Edit, Delete categories
- Cloudinary integration for image upload

### 📜 Order Management
- View all orders
- Change order status (Pending, Shipped, Delivered)

### 🗄 Database
- Firestore for storing product, category, and order details
- Real-time updates for orders

### 🎨 UI/UX
- Responsive design
- Easy navigation for product/category/order management

---

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Firebase (Auth, Firestore)
- **Image Storage**: Cloudinary
- **Styling**: Tailwind CSS
